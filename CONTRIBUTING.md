# Contributing

Thanks for your interest in NYC Pantry ABM.

## What's welcome

- **Bug reports, questions and suggestions.** Please [open an issue](https://github.com/jonathan-chin/pantry-abm/issues/new/choose).
- **Requests to use the code.** The project is all rights reserved for now. To copy, modify, host or build on it, use the "Request permission to use the code" form on the same page.

## Code contributions

Pull requests aren't being accepted for now, and will be closed.

This is research in progress, and the code is expected to move to an open license later. Merging code from other people before then would mean needing each contributor's agreement to make that change. If you have an idea for the code, describe it in an issue.
